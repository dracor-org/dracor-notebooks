# DraCor Notebooks

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24237154.svg)](https://doi.org/10.5281/zenodo.24237154) [![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/dracor-org/dracor-notebooks/main)

A collection of notebooks to showcase the work with data extracted from [DraCor corpora](https://dracor.org) and in particular the [DraCor API](https://dracor.org/doc/api).

:::{admonition} New to DraCor?
:class: tip
The [DraCor Textbook](https://dracor-org.github.io/dracor-textbook/) introduces DraCor, the API and the programming basics. Its [Appendix A](https://dracor-org.github.io/dracor-textbook/appendix/running-the-textbook-as-an-interactive-notebook.html) explains how to run notebooks on the EOSC EU Node Binder or on mybinder.org.
:::
