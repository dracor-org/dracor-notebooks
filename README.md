# DraCor Notebooks

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24237154.svg)](https://doi.org/10.5281/zenodo.24237154) [![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/dracor-org/dracor-notebooks/main)

A collection of notebooks to showcase the work with data extracted from [DraCor corpora](https://dracor.org) and in particular the [DraCor API](https://dracor.org/doc/api).

**The notebooks are published as a book: [dracor-org.github.io/dracor-notebooks](https://dracor-org.github.io/dracor-notebooks/).**

The badges show whether a notebook runs with the current DraCor API on dracor.org, and with the next release on the staging server, as last tested (see [Tested environments](https://dracor-org.github.io/dracor-notebooks/appendix/tested-environments.html)).

## Maintainers and contributing

The DraCor Notebooks are maintained by Ingo Börner, Henny Sluyter-Gäthje and Frank Fischer, with the support of Carsten Milling (technical lead of DraCor). Ideas for new notebooks, corrections and questions are welcome: please open an [issue](https://github.com/dracor-org/dracor-notebooks/issues) or write to info@dracor.org. See [CONTRIBUTING.md](CONTRIBUTING.md) for how to contribute, and [Get in Touch](https://dracor.org/doc/get-in-touch) on dracor.org for other ways to reach the DraCor community.

**Use of AI:** We use AI, namely Claude Code (Anthropic), to test, maintain and update the notebooks. All changes are reviewed by a maintainer.

## Running the notebooks

There are several ways to run the notebooks:

- **From the book:** on each page of the [DraCor Notebooks book](https://dracor-org.github.io/dracor-notebooks/), the launch menu (rocket icon) opens the notebook on the [EOSC EU Node Binder](https://binder.eu-2.notebooks.open-science-cloud.ec.europa.eu) (institutional login), on [mybinder.org](https://mybinder.org) (no login) or in [Google Colab](https://colab.research.google.com).
- **On mybinder.org** for the whole repository: [![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/dracor-org/dracor-notebooks/main)
- **Locally:** clone the repository and install the packages of a notebook from the `requirements.txt` in its folder, e.g. `pip install -r dts/requirements.txt` (Python 3.10 or newer). Folders without their own `requirements.txt` have not been updated yet; their tested package versions are listed in [environments/](environments/).

Appendix A of the [DraCor Textbook](https://dracor-org.github.io/dracor-textbook/appendix/running-the-textbook-as-an-interactive-notebook.html) explains step by step how to run notebooks on the EOSC EU Node Binder and on mybinder.org.

The notebooks query the DraCor API. The server is set at the beginning of each notebook, usually in the variable `api_base`.

## Status and tested environments

The notebooks were last tested on 2026-11-15 against DraCor API v1 1.4.1, the legacy API v0 0.91.3 and staging 1.5.0-rc.1. Not all of them run with current package versions: some need PyDraCor 2.0.0, some still use the legacy API v0, which will be shut down. [TESTED-ENVIRONMENTS.md](TESTED-ENVIRONMENTS.md) lists, for each notebook, the API version, the server, the PyDraCor and Python versions and the test result. The exact package sets are in [environments/](environments/).
